# 🏍️ Aventuras sin Rumbo - Proyecto Completo

## 📁 Estructura del Proyecto

### 📝 **Guiones/**
Aquí van todos tus guiones de grabación. Cada episodio tiene su guión.
- `Dia1_BarcoAbandonado.md` - Guión para grabar el Día 1
- Agregar nuevos guiones para cada aventura

### 🎥 **Videos/**
- **Grabados/** → Videos sin editar, tal cual los grabás con el teléfono
- **Editados/** → Videos ya editados, listos para publicar

### 🎵 **Recursos/**
Materiales que usas para editar:
- **Musica/** → Canciones para los videos (sin copyright)
- **Transiciones/** → Efectos de transición
- **Efectos/** → Sound effects, overlays

### 📊 **Estrategia/**
Documentos sobre la estrategia general:
- `Playbook_Completo.html` - Todo el sistema de contenido
- `Calendario_Publicacion.md` - Cuándo publicar en cada plataforma
- `Roadmap_Monetizacion.md` - Plan de ingresos

### 📈 **Analytics/**
Tracking de métricas:
- `Tracking_Semanal.xlsx` - Followers, views, engagement
- Copiar datos de TikTok, Instagram, YouTube aquí

### 📲 **Publicacion/**
Versiones finales para cada plataforma:
- **TikTok/** → 1080x1920, 60-90seg
- **Instagram/** → 1080x1920, 30-90seg
- **YouTube_Shorts/** → 1080x1920, 15-60seg
- **YouTube_Long/** → 1920x1080, 8-15min

---

## 🚀 Workflow Típico

1. **GRABAR** → Video va a `Videos/Grabados/`
2. **EDITAR** → Usa el guión de `Guiones/` y recursos de `Recursos/`
3. **GUARDAR EDITADO** → Va a `Videos/Editados/`
4. **EXPORTAR VERSIONES** → Para cada plataforma en `Publicacion/`
5. **PUBLICAR** → Sube a TikTok, Instagram, YouTube
6. **TRACKEAR** → Copia métricas a `Analytics/`

---
